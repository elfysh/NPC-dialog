# Skyrim Character AI

Программная реализация ИИ для создания реалистичного диалогового поведения NPC в компьютерных играх (на примере Skyrim).

## Возможности

- Генерация диалогов на русском языке
- Учёт игрового контекста (локация, активный квест)
- Поиск по базе знаний (RAG) — 28k чанков игровых текстов
- LoRA-адаптация модели под лор игры
- Потоковая генерация ответов

## Технологии

- **LLM**: Mistral 7B (Vikhr Nemo) + QLoRA
- **Поиск**: FAISS (IndexFlatIP)
- **Фреймворки**: PyTorch, FastAPI, Streamlit

## Запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск API
python app.py
```

## API эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/setup` | Инициализация персонажа |
| POST | `/setup/stream` | Инициализация (SSE) |
| POST | `/chat` | Отправка сообщения |
| POST | `/chat/stream` | Отправка сообщения (SSE) |
| POST | `/reset` | Сброс сессии |
| GET  | `/health` | Проверка статуса |

## Пример запроса

```json
POST /setup
{
  "session_id": "user_123",
  "character_name": "Генерал Тулий",
  "location": "Солитьюд",
  "active_quest": "Битва при Вайтране",
  "player_query": "Приветствую, генерал"
}
```

## Структура

- `app.py` — FastAPI сервер
- `character_bot.py` — основная логика генерации
- `config.py` — конфигурация
- `data/` — база знаний и FAISS индекс
